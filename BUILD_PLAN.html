Week-by-week

Week 1 — Snap + adapt

Mon: Fork sole.tax MTD module into vat.law/runtime. Stand up Supabase project. Brand the runtime (indigo theme). Set up Stripe products + 3 tiers + annual variants. Create the 11 tables from PRODUCT_SPEC.html DB schema with RLS and audit triggers.

Tue–Wed: Clone form.law new-co webhook · pension.law 90/60/30/7-day cron · immigration.law partner-referrer pattern. Wire the cross-vertical event subscriptions (form.law / sole.tax / accounts.law / landlord.tax).

Thu–Fri: Auth gate (Supabase magic link). Dashboard skeleton with KPI cards (next return due · penalty-point exposure · pending QA). Free-tier threshold checker /api/threshold/check ships to landing page.

Week 1 gate: a logged-in customer can connect their HMRC sandbox account, see their next obligation pulled live, and submit a hard-coded 9-box return through MTD to sandbox.

Week 2 — Net-new engines I (Pro tier core)

Mon–Tue: Build partial-exemption calculator module. Standard method + de minimis + annual adjustment. Authored CTA-partner methodology memo template. trained QA reviewer prompt library entry "PE-001 Partial Exemption Memo Review."

Wed: Build DRC matrix module. Sub-contractor classification · end-user / intermediary determination · CIS overlay · invoice labelling. /api/drc/classify-batch route.

Thu: Build margin scheme + TOMS module. Stock-book maintenance · margin math · TOMS pre-payment. Templates for second-hand-goods + TOMS quarterly records.

Fri: CTA partner contracts signed (3 seed firms). trained QA review team training session 1 of 2 (the Pro-tier complex-VAT prompts).

Week 2 gate: a Pro-tier customer can run a partial-exemption calculation end-to-end · trained QA reviewer sees the queued review · CTA partner sees the sign-off request · methodology memo PDF lands in Supabase Storage.

Week 3 — Net-new engines II (Cross-Border + enquiry)

Mon: OSS / IOSS engine. Country-by-country member-state rate table. Place-of-supply classifier (B2B / B2C / digital / goods).

Tue: Postponed VAT accounting reconciliation. C79 / PIVA monthly statement parser. EORI helper.

Wed: HMRC enquiry response studio. Notice classifier · audit-trail extractor · response-pack drafter · CTA partner sign-off chain. /api/enquiry/intake route + n8n flow.

Thu: Capital goods scheme tracker. 10-year (land/buildings) / 5-year (computers) adjustment cycle.

Fri: Bookkeeping integrations. Xero OAuth + invoice pull. Sage Business Cloud API. QuickBooks Online API. FreeAgent API.

Week 3 gate: Cross-Border tier customer can draft an OSS return · upload an HMRC notice PDF · trigger the enquiry studio · trained QA review queues the pack · CTA partner signs.

Week 4 — Hardening · pen test · launch

Mon–Tue: Light-touch third-party penetration test. Fix anything flagged. Lock CSP. Confirm RLS on every table.

Wed: Live HMRC MTD sandbox full-cycle test (auth · obligation · submit · acknowledge) on a real test VRN. End-to-end audit trail validated.

Thu: India team training session 2 of 2. Landing page live at vat.law. Pricing page live. Sign-up flow live. Stripe live.

Fri: Cross-vertical launch announcements (form.law / sole.tax / accounts.law / landlord.tax in-product banners). LinkedIn launch post. Hand-off to operating mode.

Launch gate (Friday): 10 paid trials · 3 Pro returns submitted via MTD · 0 critical bugs · trained QA reviewer touch-time < 12 minutes per Pro return.
